# Import provenance

This standalone repository imports the tracked marketing website files from
https://github.com/ufo-files/nearfield, branch `main`, at commit
`ccaea1978c755324dce66c69f9e45c77cd34e539`, using `git archive`.
The source Git history and native application were not imported.

The initial import removes the legacy OpenAI Sites hosting configuration and
the Sites/Cloudflare plugins and bindings from the Vite configuration, retaining
Vinext, the existing dependencies, and the original dependency lockfile.

Repository ownership does not change authorship or grant new license rights.
The imported source contains no standalone LICENSE file; no new license is
asserted here. Existing inline third-party notices are preserved. Nearfield
artwork and the Signal icon retain their respective owners' rights and are not
claimed as Hush Line-created artwork.
